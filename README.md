## 💻 How to View & Run the Website

### Option 1: Direct Browser Open (No Setup Required)
Simply double-click [index.html](index.html) or right-click and choose **"Open with Google Chrome"** (or Edge/Firefox/Brave).

### Option 2: Using Node.js / NPM (Local Dev Server)
```bash
# Start a simple local server
npx serve .

# Or using live-server with auto-reload:
npx live-server . --port=3000
```
